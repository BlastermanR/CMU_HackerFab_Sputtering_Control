================================================================================
        SputterOS v0.5 - IMPLEMENTED SYSTEM ARCHITECTURE
================================================================================
TARGET HARDWARE:  RP2350 (Pico 2) @ 150 MHz, dual Cortex-M33 cores
EXECUTION MODEL:  Deterministic AMP — SputterOS kernel assigns tasks to cores
FRAMEWORK:        SputterOS v0.5 (lib/SputterOS git submodule)
BUILD SYSTEM:     CMake + Ninja, Pico SDK 2.2.0, C++17
================================================================================

1. CORE ARCHITECTURE
--------------------------------------------------------------------------------
SputterOS provides a `SystemBuilder<Cfg>` pattern that wires tasks, safety
monitors, and HAL bindings at compile time.  `System<Cfg>::run(coreId)` is the
blocking scheduler entry point on each core.

    Core 0 — ScheduledControlTask (100 Hz)
        1. Evaluate ISafetyMonitor array → forceSafeAbort() on first failure.
        2. Drain up to kMaxCommandsPerTick commands → handleCommand().
        3. Call IUserApplication::tick() → device polling + process phase logic.

    Core 1 — ScheduledCommsTask
        Reads USB bytes via IStream, parses text commands into Cfg::Command
        packets, pushes them to the kernel's lock-free queue.

    Core 1 — BackgroundDiagnosticsTask
        Drains TelemetryLogger ring buffer to USB, monitors timing budgets,
        kicks the watchdog.

2. CONFIGURATION (include/config/SputteringCfg.h)
--------------------------------------------------------------------------------
Satisfies the SputterOS ConfigTraits contract:
    State enum:   IDLE(0), PUMP_DOWN(1), PURGE(2), IGNITION(3),
                  DEPOSITING(4), VENTING(5), FAULT(6)
    CmdID enum:   SET_STATE(0), ABORT(1), SET_ARGON_FLOW(2),
                  SET_OXYGEN_FLOW(3), SET_PUMP_SPEED(4), SET_VERBOSITY(5)
    Command:      { CmdID id; uint8_t targetDevice; float value; }
    Constants:    kCoreCount=2, kQueueCapacity=16, kControlBudgetUs=10000

3. USER APPLICATION (src/SputteringApp.cpp)
--------------------------------------------------------------------------------
Implements IUserApplication<SputteringCfg>:
    init()           — Configures MFC gas types (O2, Ar), gauge, pump.
    tick()           — Polls all devices, delegates to active IProcessState.
    handleCommand()  — Routes SET_STATE → transitionTo(), ABORT → forceSafeAbort(),
                       SET_ARGON_FLOW → mfc2.setSetpoint(), etc.
    forceSafeAbort() — Gas off, pump off, set FAULT, clear active phase.
    transitionTo()   — Calls onExit/onEnter on phase objects, updates state.

4. PROCESS PHASES (src/logic/ProcessPhases.cpp)
--------------------------------------------------------------------------------
Each phase implements IProcessState { onEnter(), execute(), onExit() }:

    PumpDownPhase    — signalPumpOn(), wait for pressure ≤ 0.1 hPa or 120s timeout.
    PurgePhase       — Set argon to 50 sccm, wait 30s.
    IgnitionPhase    — Set argon to 20 sccm, wait 15s. @todo: RF power.
    DepositingPhase  — Set argon to 15 sccm, wait 60s. Shuts off gas on exit.
    VentingPhase     — Gas off, pump off, ventPump(), wait for ≥ 900 hPa or 120s.

    State transitions call SputteringApp::transitionTo().
    Timeouts cause a FAULT transition (PumpDown) or IDLE (Venting).

5. SAFETY MONITORS (include/safety/SafetyMonitors.h)
--------------------------------------------------------------------------------
    OverPressureMonitor — isSafe() when gauge.getPressure() ≤ threshold (10 hPa).
    PumpHealthMonitor   — isSafe() always true; pump driver has no fault pin yet.

    Monitors are evaluated by ControlTask BEFORE every app tick.  First failure
    triggers IUserApplication::forceSafeAbort().

6. HAL & OSAL BINDINGS
--------------------------------------------------------------------------------
    USBStream     (include/hal/)   — IStream wrapping Pico SDK stdio USB.
    PicoMutex     (include/osal/)  — IMutex wrapping Pico SDK mutex_t.

7. DEVICE DRIVERS (src/core0/, include/core0/)
--------------------------------------------------------------------------------
    AlicatMFC      — RS-232 Alicat mass flow controller (PIO UART).
    PfeifferGauge  — RS-485 Pfeiffer MPT200 pressure gauge (hardware UART).
    PfeifferPump   — RS-485 Pfeiffer TC110 turbo pump (hardware UART).

    Global instances defined in GlobalDevices.cpp:
        mfc1 (O2), mfc2 (Ar), gauge, pump.

8. ENTRY POINT (src/core0/main.cpp)
--------------------------------------------------------------------------------
    1. stdio_init_all(), wait for USB connection.
    2. Construct USBStream, SafetyMonitors, SputteringApp, PicoMutex.
    3. SystemBuilder<SputteringCfg>::build() — wires stream, clock source,
       telemetry drain, mutex, safety monitors, and application.
    4. multicore_launch_core1( System::run(1) ).
    5. System::run(0) — blocks forever on Core 0 scheduler.
